Assessment / evaluation support

Course Evaluation & Assessment Planning Toolkit.

A standalone toolkit for the part of course development that can get vague too quickly: deciding what learners should be able to do, what evidence would show it, and how the team will know what to improve after launch.

This object is self-contained and was built as a practical course-development support. It is meant to help a team ask better assessment and evaluation questions, not to replace the local judgment needed for a specific course.

Build context: Standalone HTML, inline CSS, assessment planning, rubric development, usability review, and portfolio adaptation from graduate instructional design work.

What was happening

Course review can drift into checking screens, wording, or completion requirements without stopping long enough to ask whether the course has a visible chain of evidence. The practical question is simple, but not always easy: do the goals, learner actions, assessments, rubrics, usability checks, and post-launch data actually line up?

What I built

I rebuilt earlier graduate work in assessment design, rubric development, instructional evaluation, survey planning, and usability testing into a single web-based toolkit. It gives course-development teams a set of reusable frames: an alignment map, assessment design check, rubric planning frame, usability checklist, post-launch evidence log, and a short process for using the pieces without treating the template as the answer.

What it demonstrates

Assessment planning Course evaluation Rubric development Usability review Accessibility checks Course-development workflow

My role

I translated academic assessment and evaluation work into a practical support object for course teams. The point was not to create a finished answer for every course. It was to make the important questions visible enough that a team can adapt them to the actual learners, constraints, evidence, and review standards in front of them.
